# ゆずのおこづかい管理

カテゴリ別に毎月積み立て、使った分を差し引いていく個人用Webアプリです。初期カテゴリの積立額は原神 ¥2,500、グッズ ¥3,000、仕事中の食費 ¥7,500、その他趣味・おやつ ¥5,000です。

## 使い方

- ホームの「支出を記録」から日付、カテゴリ、金額、メモを登録します。未来の日付は登録できず、残高を超える支出には確認が出ます。
- 月が変わると、アプリを開いたときに未記録の月の積立を追加します。数か月ぶりに開いても、各月分を一度ずつ追加します。
- 設定から積立額を変えると、翌月以降に適用されます。過去の積立履歴はその時点の金額で残ります。
- 設定の「現在残高を設定」「残高を増減」で初期残高や臨時積立を記録できます。
- 履歴画面でカテゴリ・月を絞り込み、履歴を編集または削除できます。
- データはそのブラウザのIndexedDBに保存されます。設定からJSONバックアップを書き出し、端末変更やブラウザのデータ削除に備えて保管してください。

## パソコンで起動する

1. ZIPを展開します。
2. 展開したフォルダをターミナルで開きます。
3. Python 3がある場合は `python3 -m http.server 8000` を実行します（Windowsでは `py -m http.server 8000`）。
4. ブラウザで `http://localhost:8000` を開きます。

HTMLファイルを直接開く方法（`file://`）では、IndexedDBやPWAが正しく動かないブラウザがあります。ローカルサーバーを使ってください。

## iPhoneで使う・ホーム画面に追加する

GitHub Pagesで公開する例：

1. GitHubで新しいリポジトリを作り、展開したアプリのファイルをアップロードして保存します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** の Source を **Deploy from a branch** にし、公開ブランチ（通常は `main`）とフォルダ `/ (root)` を選んで **Save** します。
4. 表示されたHTTPSの公開URLをiPhoneのSafariで開き、共有ボタンから「ホーム画面に追加」を選びます。

GitHub Pagesの現在の設定手順は[GitHub公式ガイド](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)も参照してください。GitHub Pagesのサイトはインターネット上に公開されます。このアプリの保存データはブラウザ内にとどまりますが、リポジトリに個人情報を入れないでください。

このアプリはサーバーに家計データを送信しません。Safariのサイトデータを消すとアプリ内のデータも消えるため、JSONバックアップを別の場所にも保存してください。

## テスト

Node.js 18以降で、フォルダ内から `node --test tests/ledger.test.cjs` を実行します。月またぎ、複数月の未起動、積立額変更、支出編集・削除、重複積立防止、月別集計を確認します。
